# КОД СУДЬБЫ | Матрица и Нумерология

Telegram-бот для нумерологических расчётов с фриумиум-моделью.

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env` и заполните переменные
4. Запустите: `python -m bot.main`

## Docker

```bash
docker-compose up -d
```

## Функции

- 🔢 Бесплатные расчёты (3 в месяц)
- 🔮 Премиум-отчёты (PDF)
- 👥 Совместимость
- 📊 Квадрат Пифагора
- 🎁 Реферальная программа
